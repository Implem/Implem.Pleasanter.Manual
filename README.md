**このリポジトリには、いまは日本語版の原稿だけを置いています。**

## このリポジトリについて

**マニュアルの内容に気づいたことを教えていただくための場所です。**

誤字、説明の誤り、古くなった記述、分かりにくい箇所など、どんなことでもかまいません。
[Issue](../../issues) でお知らせいただくか、Pull Request をお送りください。

> **このリポジトリは配信元ではありません。**
> サイトは弊社内のリポジトリからビルドして配信しています。ここはその**内容を写したもの**で、
> 定期的に更新されます。
>
> そのため、**いただいた Pull Request はここでマージされません。**
> 内容を弊社の担当者が確認したうえで弊社内のリポジトリへ取り込み、次の同期でここへ反映します。
> 反映後に、取り込み先が分かる形でお返事し、こちらの Pull Request は閉じさせていただきます。
> **マージされずに閉じられた場合でも、内容が採用されなかったという意味ではありません。**

## 構成

```
ja/docs/    日本語版のページ
contribute/ 書き方の案内
```

ページは Markdown で書かれています。front matter（ファイル先頭の `---` で囲まれた部分）は
サイトの生成に使われるので、**内容を直すときは本文だけを変更してください。**

各ディレクトリの `.nav.yml` はナビゲーションの並びと表示名を決めています。

## 画像について

**画像の実体はこのリポジトリに含まれていません。** サイトと同じストレージから配信しています。

Markdown の中の画像は、サイトで使っている画像の URL（`https://pleasanter.org/files/images/…`）を
直接指しているので、GitHub の画面でもそのまま表示されます。
**画像の URL は変えないでください。**

画像の差し替えが必要な場合は、Issue でお知らせください。

## サイトの生成について

サイトの生成に使う設定やスクリプトは、このリポジトリには含めていません。
