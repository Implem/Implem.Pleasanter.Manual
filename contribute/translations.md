# 日本語版と英語版

PUM は日本語版（`ja/`）と英語版（`en/`）で**プロジェクトを分けて**います。同じ内容のページが両方にあり、ビルドも別々です（[プリザンターユーザマニュアルの構造](pum-structure.md)）。

## 対応するページの見つけ方

多くのページは、**両言語で同じパス**に置かれています。

```
ja/docs/users-guide/table/record-authoring/create-records/table-record-import.md
en/docs/users-guide/table/record-authoring/create-records/table-record-import.md
```

ページごとの言語切替と `hreflang` は、**このパスの一致**で相手を決めています（#190）。相手の言語に同じパスのページがなければ、言語切替はその言語のトップへ飛びます。

front matter の `translationKey` は旧CMSの名残です。**現行のビルドでは参照していません。**対応を調べる手がかりにはなりますが、これを直しても言語切替の行き先は変わりません。

## 英語版は日本語版に追いついていないところがあります

日本語版で使っている記法（注意書き・折りたたみ・タブ・手順・脚注など）が、英語版では地の文のままになっているページがあります。英語版を直すときは、**対応する日本語版のページを開いて見比べてください。**構成が違っていたら、日本語版に合わせるのが原則です。

## 片方の言語だけの提案も受け付けます

日本語版と英語版の**両方を直せなくてもかまいません。**片方だけの提案も受け付けます（#282 で方針を決めました）。

- プルリクエストの本文に「**日本語版のみ**」「**英語版のみ**」と書き添えてください
- もう一方の言語は、弊社の担当者が**取り込むときに追随の issue を立てて**直します。提案していただいた方が追随する必要はありません

## 翻訳するときに気をつけること

- **画面の項目名は、その言語の画面に出ている文字をそのまま書きます。**訳し下ろさないでください（[用語と表記](glossary.md)）
- **画像は言語ごとに別のものです。**英語版のページには英語の画面の画像が必要です
- 英語版のページにも、日本語版と同じ**対応バージョン表**と**関連情報**を置きます
