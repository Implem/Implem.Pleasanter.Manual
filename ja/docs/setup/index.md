様々な環境にプリザンターをセットアップする手順を説明します。

!!! warning "セットアップをはじめる前に"

    プリザンターは大規模利用を想定した、エンタープライズ向けのノーコード・ローコードツールです。セットアップには、一定の手間と労力をかける必要があります。

    -   [プリザンター技術支援サービス](https://pleasanter.org/tec-service/)

もっと手軽にプリザンターを試したい場合は、[こちらのマニュアル](../getting-started/index.md)を参照してください。
