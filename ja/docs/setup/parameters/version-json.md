## 設定値

本パラメータファイルの設定値は下記の通りです。  

|パラメータ名|設定例|説明|
|:--|:--|:--|
|ShowDeadline|true|商用ライセンス使用時の有効期限を表示しない場合にはfalseを指定。|
|ShowLicensee|true|商用ライセンス使用時の使用者を表示しない場合にはfalseを指定。|
|ShowMaximumNumberOfUsers|true|商用ライセンス使用時のユーザ数上限を表示しない場合にはfalseを指定。|
