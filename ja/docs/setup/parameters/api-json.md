## 設定値

本パラメータファイルの設定値は下記の通りです。

| パラメータ名         | 設定例 | 説明                                                                                                                                                                                        |
| :------------------- | :----- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ApiVersion           | 1.1    | ApiVersionの既定値を指定します。<br>1.0または1.1を指定できます。                                                                                                                            |
| Enabled              | true   | true<br>API機能を有効化します。<br><br>false<br>API機能を無効化します。                                                                                                                     |
| PageSize             | 200    | レスポンスで返される1ページあたりのデータ量を指定します。<br><br>0<br>該当する全データをページングせずに取得します。                                                                        |
| LimitPerSite         | 0      | サイトごとの1日に利用可能なAPIのリクエスト回数を制限します。例えば1000を指定した場合、1つのサイトに対して1日に1000リクエストまで利用可能となります。<br><br>0<br>制限なく利用可能とします。 |
| Compatibility_1_3_12 | false  | true<br>バージョン1.3.12.0以前と互換性のある動作となります。<br><br>false<br>バージョン1.3.12.0以前と互換性を無視し、指定したAPIバージョンで動作します。[^1]                                                                                                                                |

[^1]: 詳細は[既定のAPIバージョン 1.1 への変更および旧バージョンとの互換性について](../version-up-migration/migration/default-api-version-1-1.md)を確認してください。
