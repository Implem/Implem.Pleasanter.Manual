## 設定値

本パラメータファイルの設定値は下記の通りです。

|パラメータ名|設定例|説明|
|:--|:--|:--|
|Responsive|true|レスポンシブデザインの有効化/無効化をtrue/falseで指定します。|
|SiteSettingsResponsive|true|サイト設定のレスポンシブデザインの有効化/無効化の既定値をtrue/falseで指定します。|
|EnableMobileCamera|false|モバイル端末でレコードへ画像を追加する際に使うカメラ起動ボタンの有効化/無効化をtrue/falseで指定します。|

|:--|:--|
