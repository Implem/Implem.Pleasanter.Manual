## 設定値

本パラメータファイルの設定値は下記の通りです。  

|パラメータ名|設定例|説明|
|:--|:--|:--|
|Enabled|true|ユーザ招待機能の有効化/無効化をtrue/falseで指定します。|
|PrivilegedUserOnly|true|trueで特権ユーザにのみメニューが表示します。|
|ApprovalRequestTo|sample@example.com|招待されたユーザが承認依頼を行った際に通知するメールアドレスを指定します。 1つのメールアドレスのみ指定可能です。|
