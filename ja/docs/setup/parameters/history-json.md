## 設定値

本パラメータファイルの設定値は下記の通りです。  

|パラメータ名|設定例|説明|
|:--|:--|:--|
|Restore|true|履歴画面における復元ボタンの表示有無をtrue/falseで指定します。|
|PhysicalDelete|true|履歴画面におけるごみ箱から削除ボタン(物理削除)の表示有無をtrue/falseで指定します。|
