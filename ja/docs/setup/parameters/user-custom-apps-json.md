## 注意事項

パラメータ変更時は[パラメータ変更時の確認事項](parameter-edit.md)を確認してください。

## 設定値

本パラメータファイルの設定値は下記の通りです。  

|パラメータ名|設定例|説明|
|:--|:--|:--|
|Enabled|true|カスタムアプリの有効化/無効化を指定。有効化した場合はサイトの新規作成の画面にカスタムアプリのタブが表示されます。|
|CustomAppsMax|300|カスタムアプリの登録上限件数を指定。|
