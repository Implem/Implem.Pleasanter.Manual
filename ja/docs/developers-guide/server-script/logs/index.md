## 概要

[サーバスクリプト](../index.md)でログの出力を行うためのオブジェクトです。ブラウザの開発者ツールのコンソール上への表示とシステムログへの記録を行うことができます。

## プロパティ

プロパティはありません。

## メソッド

|No|Name|Description|
|:---|:---|:---|
|1|[LogInfo](server-script-logs-log-info.md)|ログの種類：Infoとしてログを表示、出力します。|
|2|[LogWarning](server-script-logs-log-warning.md)|ログの種類：Warningとしてログを表示、出力します。|
|3|[LogUserError](server-script-logs-log-user-error.md)|ログの種類：UserErrorとしてログを表示、出力します。|
|4|[LogSystemError](server-script-logs-log-system-error.md)|ログの種類：SystemErrorとしてログを表示、出力します。|
|5|[LogException](server-script-logs-log-exception.md)|ログの種類：Exceptionとしてログを表示、出力します。|
|6|[Log](server-script-logs-log.md)|指定したログの種類でログを表示、出力します。|
