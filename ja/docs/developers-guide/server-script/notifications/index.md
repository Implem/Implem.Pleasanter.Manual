## 概要

通知を行うためのオブジェクトを生成、取得することができます。

## メソッド

|メソッド|概要|
|:---|:---|
|[Get](server-script-notifications-get.md)|通知の設定を取得|
|[New](server-script-notifications-new.md)|通知のオブジェクトを生成|

## 注意事項

こちらは[サーバスクリプト](../index.md)で使用するメソッドです。[スクリプト](../../../managers-guide/manage-table/scripts/index.md)では使用できません。
