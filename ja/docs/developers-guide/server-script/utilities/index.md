## 概要

[サーバスクリプト](../index.md)でユーティリティ機能を提供します。

## プロパティ

プロパティはありません。

## メソッド

|No|Name|Description|
|:---|:---|:---|
|1|[ConvertToBase64String](server-script-utilities-convert-to-base64-string.md)|引数に渡した文字列をBase64形式の文字列に変換します。|
|2|[EmptyTime](server-script-utilities-emptytime.md)|未設定を表す日時「0001/01/01 0:00:00」を返します。|
|3|[InRange](server-script-utilities-inrange.md)|指定された日時がプリザンターが扱える日時の有効範囲内かチェックします。|
|4|[MaxTime](server-script-utilities-maxtime.md)|ローカル時間における最大日時をUTCで返します。|
|5|[MinTime](server-script-utilities-mintime.md)|ローカル時間における最小日時をUTCで返します。|
|6|[Today](server-script-utilities-today.md)|ローカル時間における当日の0時の時刻をUTCで返します。|

## 対応バージョン

|対応バージョン|内容|
|:--|:--|
|1.4.15.0 以降|メソッドEmptyTime、MinTime、MaxTimeを追加|
