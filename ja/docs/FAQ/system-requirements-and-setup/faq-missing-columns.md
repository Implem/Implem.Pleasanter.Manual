## 回答

[Enterprise Edition](https://pleasanter.org/support)へアップグレードしてください。

---

## 概要

プリザンターの「Community Edition」は[分類項目](../../managers-guide/manage-table/editor/editor-settings/columns/table-management-class.md)、[数値項目](../../managers-guide/manage-table/editor/editor-settings/columns/table-management-num.md)、[日付項目](../../managers-guide/manage-table/editor/editor-settings/columns/table-management-date.md)、[説明項目](../../managers-guide/manage-table/editor/editor-settings/columns/table-management-description.md)、[チェック項目](../../managers-guide/manage-table/editor/editor-settings/columns/table-management-check.md)、[添付ファイル項目](../../managers-guide/manage-table/editor/editor-settings/columns/table-management-attachments.md)の各項種別毎に26個、計156項目を利用することができます。項目数を増やしたい場合は[Enterprise Edition](https://pleasanter.org/support)をご利用いただくことで項目を追加することが可能です。

| DB | Enterprise Editionで利用できる項目の上限 |
| ---- | ---- |
| SQL Server | 6つの項目種別の合計で最大900個まで |
| PostgreSQL | 6つの項目種別の合計で最大900個まで |
| MySQL ※ | 6つの項目種別の合計で最大256個まで |

※MySQLはver1.4.9.0以降で使用できます。ver1.4.9.0より前のプリザンターはMySQLに対応していません。

[Enterprise Edition](https://pleasanter.org/support)をご利用いただくには年間サポートサービスのご契約が必要です。[Enterprise Edition](https://pleasanter.org/support)単体では販売しておりません。

[Enterprise Edition](https://pleasanter.org/support)の詳細は「[こちら](https://pleasanter.org/support)」を参照してください。

![Enterprise Edition の案内](https://pleasanter.org/files/images/ja/FAQ/system-requirements-and-setup/assets/f34ea89d6adf4877b677c41d801d1bd4.png)

## Enterprise Editionの新プラン

「[年間サポートサービス](https://pleasanter.org/support#plan)」の「ミニプラン」、「ライトプラン」でも同様に項目数を追加いただけます。

## Enterprise Editionの試用版

[Enterprise Edition](https://pleasanter.org/support)の試用版の入手方法については「[お問い合わせ](https://implem.co.jp/contact)」にご連絡ください。

## 対応バージョン

|対応バージョン|内容|
|:--|:--|
|1.4.9.0 以降|MySQLに対応|
