おおよそ、サイトは2,000サイト、レコードは1サイト当たり100,000レコードを目安としてください。

## 概要

[テーブル](../../users-guide/table/index.md)、[フォルダ](../../users-guide/folder/index.md)等の[サイト](../../users-guide/site/index.md)の作成数や、テーブルに対する登録レコード件数の最大値は下記を参照ください。なお、Pleasanter.netについてはプランによって上限を定めております。詳細は下記URLを参照してください。
https://pleasanter.net/Home/Price

|   サイト種類   | システム上の制限 | 最大値の目安 |
| :------------: | :--------------: | :----------: |
|     サイト     |        無        |    2,000     |
| フォルダの階層 |        無        |      5       |
|   レコード数   |        無        |   100,000    |
|    ユーザ数    |        無        |    10,000    |
|     組織数     |        無        |    10,000    |
|   グループ数   |        無        |    10,000    |

### 最大値の目安について

システム上の制限ではありませんが最大値の目安として参考にしてください。レコード数等が多くなるとパフォーマンスに影響する場合があります。パフォーマンスはアクセス制御の設定、リンクの設定、フィルタでの検索条件、項目数、項目に格納されている文字量、ハードウェア性能、同時アクセス数など複合的な要因で悪化する場合があります。そのため、レコード数が最大値の目安の範囲内であっても、十分なパフォーマンスが出ないケースがございます。

プリザンターのパフォーマンスは、サーバの性能や、上述の通りサイトの構築方法によっても大きく変わります。実際には、各目安以上の条件でプリザンターが優れたパフォーマンスを発揮している実例も多く有りますが、個別の環境や要件に応じて最適なパフォーマンスを実現するためには事前の検証が必須となります。お客様固有のニーズに合わせて、パフォーマンスを最適化するための個別のアドバイスやサポートの提供が可能ですので、まずはお気軽にご相談ください
