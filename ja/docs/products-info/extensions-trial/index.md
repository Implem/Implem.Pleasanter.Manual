## 概要

Pleasanter Extensionsのトライアルについて説明します。Community Editionを拡張する様々な機能を、期間限定で試用できます。

### 試用期間

トライアル開始から90日間利用できます。

### 試用できる機能

以下の機能をトライアルで利用できます。

#### 1. Pleasanter Extensions：[項目拡張](../enterprise-edition/columns-expansion/enterprise-edition-columns-expansion-1.4.8.md)

期限付きテーブル、記録テーブルに対して[分類項目](../../managers-guide/manage-table/editor/editor-settings/columns/table-management-class.md)をそれぞれ100個追加した状態でトライアルを開始できます。トライアル期間内であれば、分類項目以外の項目も追加できます。追加手順は[追加する項目数の設定](trial-period-extended-columns.md)を参照してください。[項目拡張](../enterprise-edition/columns-expansion/enterprise-edition-columns-expansion-1.4.8.md)の詳細は「[項目拡張手順（ver.1.4.8以降）](../enterprise-edition/columns-expansion/enterprise-edition-columns-expansion-1.4.8.md)」の「概要」および「注意事項」「前提条件」を参照ください。  

![Pleasanter Extensions の項目拡張を紹介する画像](https://pleasanter.org/files/images/ja/products-info/extensions-trial/assets/bdc901c6fee44303a4d5e0d1c3d3e8b7.png)

#### 2. Pleasanter Extensions：[Pleasanter Code Assist](../pleasanter-extensions/pleasanter-code-assist/pleasanter-code-assist-create-workfolder.md)

Visual Studio Codeでスクリプトなどのソースコードの保存と同時にプリザンターへの登録・更新ができるソフトウェアを試用できます。[Pleasanter Code Assist](../pleasanter-extensions/pleasanter-code-assist/pleasanter-code-assist-create-workfolder.md)の特徴や動作環境、機能一覧などの機能概要は[Pleasanter Code Assist：機能概要](../pleasanter-extensions/pleasanter-code-assist/pleasanter-code-assist-overview.md)を参照ください。

![Pleasanter Code Assist を紹介する画像](https://pleasanter.org/files/images/ja/products-info/extensions-trial/assets/e7e45ef82e5740d69295ef856dd50b71.png)

#### 3. Pleasanter Extensions：[Pleasanter Site Visualizer](../pleasanter-extensions/pleasanter-site-visualizer/pleasanter-site-visualizer-how-to-use-sites.md)

WebブラウザであるChromeまたはEdgeでテーブルの管理の設定情報の一覧表示やファイルダウンロードなどができるソフトウェアを試用できます。[Pleasanter Site Visualizer](../pleasanter-extensions/pleasanter-site-visualizer/pleasanter-site-visualizer-how-to-use-sites.md)の特徴や動作環境、機能一覧などの機能概要は[Pleasanter Site Visualizer：機能概要](../pleasanter-extensions/pleasanter-site-visualizer/pleasanter-site-visualizer-overview.md)を参照ください。

![Pleasanter Site Visualizer を紹介する画像](https://pleasanter.org/files/images/ja/products-info/extensions-trial/assets/31b742629950498cb51d5d16009db5da.png)

#### 4. 運用支援ツール（Operations Tools）

性能状況や利用状況の可視化、各種情報の一覧表示によりプリザンターの運用を支援するツールを試用できます。Pleasanter Extensions：[運用支援ツール](../pleasanter-extensions/operations-tools/index.md)のトライアルは、別途<a href="https://pleasanter.org/forms/inquiry-service" target="_blank" rel="noopener noreferrer">お申し込み</a>が必要です。[Operations Tools](../pleasanter-extensions/operations-tools/operations-tools-common-export.md)の特徴や動作環境、機能一覧などの機能概要は[Operations Tools：機能概要](../pleasanter-extensions/operations-tools/operations-tools-overview.md)を参照ください。

![運用支援ツール（Operations Tools）を紹介する画像](https://pleasanter.org/files/images/ja/products-info/extensions-trial/assets/3cc0f666b4a0489faa4c4c1470e5bff5.png)

## 制限事項

1. トライアル期間中のプリザンターのライセンスはAGPL（Community Editionのまま項目拡張を試用する形態）です。
1. Enterprise Editionにアップグレードした環境ではライセンス状態にかかわらずトライアルは実施できません。
1. トライアルの実施は1環境で1回限りです。トライアル期限切れの環境で再度トライアルを実施することはできません。
1. トライアル期間中はログイン画面およびバージョン情報画面にトライアルの情報が表示されます。この表示はトライアル期限が過ぎても表示されたままとなります。（Enterprise Editionへアップグレードすると、トライアルの情報は非表示となります。）
1. トライアル期限切れ後、拡張項目は非表示となります。（トライアル期間中またはトライアル期限切れの状態からEnterprise Editionへ拡張項目を維持した状態でアップグレードすることができます。）

## トライアルの開始可否

[トライアル](../../developers-guide/index.md)の開始可否の条件は以下のとおりです。

| ライセンス         |        状態        | トライアル開始可否 | 備考                                                                                                                             |
| :----------------- | :----------------: | :----------------: | :------------------------------------------------------------------------------------------------------------------------------- |
| Community Edition  |  トライアル未実施  |      開始可能      | 指定内容に基づき項目拡張を行います                                                                                               |
| Community Edition  |  トライアル期間中  |      開始可能      | 指定内容に基づき再度項目拡張を行います。指定内容によっては拡張した項目そのものが削除されますので、データが消失する場合があります |
| Community Edition  | トライアル期限切れ |      開始不可      | トライアル実施は1回のみです                                                                                                      |
| Enterprise Edition |         -          |      開始不可      | Enterprise Editionにアップグレードしたプリザンターではライセンス状態にかかわらずトライアルは開始できません                       |
