## 概要

Pleasanter Extensionsはプリザンターの開発・運用者向けの支援ツールおよびサンプルプログラム集です。

<div class="grid cards" markdown>

-   **Pleasanter Code Assist**

    ---

    プリザンターの開発者向けに快適な開発体験を提供する**Visual Studio Code拡張機能**。  
    :material-arrow-right: [詳細](pleasanter-code-assist/pleasanter-code-assist-overview.md)

-   **Pleasanter Site Visualizer**

    ---

    設定情報の一覧表示やファイルダウンロードができる**Chrome拡張機能**および**Edge拡張機能**。  
    :material-arrow-right: [詳細](pleasanter-site-visualizer/pleasanter-site-visualizer-overview.md)

-   **開発支援ツール Development Tools**

    ---

    ソースコードのアップロード、サイト設定移行機能などを備える開発支援ツール。  
    :material-arrow-right: [詳細](development-tools/development-tools-overview.md)

-   **運用支援ツール Operations Tools**

    ---

    プリザンターの利用状況、性能状況、アクセス権一覧などの確認や監視アラートの設定、不要サイトの削除依頼などができる運用支援ツール。  
    :material-arrow-right: [詳細](operations-tools/operations-tools-overview.md)

</div>

### サンプルプログラム Pleasanter Extensions Samples

| 名称                      | 内容                                                                                                    |
| :------------------------ | :------------------------------------------------------------------------------------------------------ |
| SearchWeb                 | プリザンターをデータストアとして利用した商品検索Webアプリケーションのサンプルプログラム                 |
| SiteSettingsExportConsole | プリザンターのサイト設定をExcelファイルにエクスポートするコンソールアプリケーションのサンプルプログラム |
| SiteSettingsImportConsole | プリザンターのサイト設定をExcelファイルからインポートするコンソールアプリケーションのサンプルプログラム |
