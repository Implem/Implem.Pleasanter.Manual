## 概要

サイドメニューについて説明します。

サイドメニューを展開していない状態でアイコンをマウスオーバーすると、ツールチップでメニュー名が表示されます。

![サイドメニューのアイコンにマウスオーバーし、ツールチップでメニュー名が出た状態](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/8fb9264eaae04b428c0a654a03a03443.png)

最下部のメニュー「プリザンター」をクリックすると、プリザンターのトップページへ戻ります。

![サイドメニュー最下部のメニュー「プリザンター」](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/86b18dececf74fecb22cae5c5be232a4.png)
