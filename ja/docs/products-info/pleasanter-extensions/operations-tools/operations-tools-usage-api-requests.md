## 概要

プリザンターの利用状況詳細としてAPIリクエスト履歴を確認できる画面です。「開始日」「終了日」を指定して最長１年間をフィルタすることができます。明細情報は「CreatedTime」の降順で表示されます。  

> **Note**  
> APIリクエスト履歴は[システムログの拡張機能](../../../managers-guide/system-log-administration/syslog-extension.md)を利用している場合のみ確認することができます。  
> 
> システムログの拡張機能 | Pleasanter  
> https://pleasanter.org/manual/syslog-extension  

![利用状況詳細のAPIリクエスト履歴画面](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/33ecf67db27348ae88280c83ee8a506f.png)

| 表示種別 | 項目 | 説明                                                              |
|------|----|-----------------------------------------------------------------|
| 表形式  | 全般 | 「開始日」「終了日」でフィルタした期間内のAPIリクエスト履歴がプリザンターのSyslogsテーブルのイメージで表示されます。 |
