## 概要

「データベース」「システムテーブル」「サイト」に上限値を入力し、更新ボタンをクリックすることでアラートの上限値を設定できます。更新が成功した場合は画面下部にメッセージが表示されます。

![監視アラートのアラート設定画面。上限値を入力して更新する](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/ae7b1d64267b49e2b3211279895c2277.png)

現在値がアラートの上限値を超えた場合は現在値が赤文字となり、アラートのアイコンが表示されます。

![現在値が上限値を超え、赤文字とアラートアイコンが表示された状態](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/aa381ce4df874d03994bd60077a40c4b.png)

| 表示種別     | 項目                             | 説明                                                             |
| :----------- | :------------------------------- | :--------------------------------------------------------------- |
| 単一テキスト | データベース：現在               | データベースの使用量の現在値（概算）が表示されます。             |
| 単一テキスト | データベース：上限               | ユーザが設定したデータベースの使用量の上限値が表示されます。     |
| 単一テキスト | システムテーブル：現在（最大値） | システムテーブルの使用量の現在値（概算）が表示されます。         |
| 単一テキスト | システムテーブル：上限（最大値） | ユーザが設定したシステムテーブルの使用量の上限値が表示されます。 |
| 単一テキスト | サイト：現在（最大値）           | サイトの使用量の現在値（概算）が表示されます。                   |
| 単一テキスト | サイト：上限（最大値）           | ユーザが設定したサイトの使用量の上限値が表示されます。           |
