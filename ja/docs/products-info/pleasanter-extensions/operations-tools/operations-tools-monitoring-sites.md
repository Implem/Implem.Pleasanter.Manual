## 概要

サイトの明細情報は「サイト名」を指定してフィルタすることができます。明細情報は「バイナリサイズ（GB）」の降順、「サイトID」の昇順、「サイト名」の昇順で表示されます。  

![監視アラートのサイト画面。サイトごとの明細情報が並ぶ](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/d47045e8cef8439db8337cfbb2c4ab62.png)

| 表示種別 | 項目  | 説明                                          |
|------|-----|---------------------------------------------|
| 表形式  | サイトID | プリザンターのサイトIDが表示されます。 |
| 表形式  | サイト名 | プリザンターのサイト名が表示されます。 |
| 表形式  | レコード件数 | プリザンターのサイトの単位でレコード件数が表示されます。 |
| 表形式  | バイナリサイズ（GB） | プリザンターのサイトの単位でバイナリサイズ（GB）が表示されます。 |
