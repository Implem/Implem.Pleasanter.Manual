## 概要

プリザンターのサイト情報一覧を確認できる画面です。「サイトID」「サイト名」「サイト種別」を指定してフィルタすることができます。明細情報は「サイトID」の昇順で表示されます。また、システムで自動的に判断されたサイトの「利用されていない可能性」が「high」「middle」「low」で表示されます。「high」または「middle」の場合は「サイト管理者への削除依頼」の明細情報に表示される「削除依頼」のボタンからメールを通知することができます。  

> **Note**  
> 「アクセスユーザ数（直近）」「セッション数（直近）」は[システムログの拡張機能](../../../managers-guide/system-log-administration/syslog-extension.md)を利用している場合のみ確認することができます。  
> 
> システムログの拡張機能 | Pleasanter  
> https://pleasanter.org/manual/syslog-extension  

![サイト情報一覧画面。サイトごとに「利用されていない可能性」などを表示する](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/2eb7599b555a42f591ea58f9d7d438f6.png)

「利用されていない可能性」についての詳細仕様は以下のとおりです。

-   更新レコード数（直近）：1件以上あるか  
-   レコード最終更新日：直近1ヶ月以内か  
-   リンクされている：他のテーブルからリンクされているか（マスタとして利用されているか）  
-   サイト作成日時：直近1ヶ月以内か  
-   サイト更新日時：直近1ヶ月以内か  

上記でYesが0の場合：（利用されていない可能性が）high＝高い  
上記でYesが1の場合：（利用されていない可能性が）middle＝どちらともいえない  
上記でYesが2～5の場合：（利用されていない可能性が）low＝低い  

| 表示種別 | 項目           | 説明                                                             |
|------|--------------|----------------------------------------------------------------|
| 表形式  | サイトID | サイトIDが表示されます。                                         |
| 表形式  | サイト名 | サイト名が表示されます。                                         |
| 表形式  | サイト種別 | サイト種別が表示されます。                                         |
| 表形式  | レコード数 | レコード数が表示されます。                                         |
| 表形式  | バイナリサイズ（GB） | バイナリサイズ（GB）が表示されます。                                         |
| 表形式  | アクセスユーザ数（直近） | 直近1ヶ月のアクセスユーザ数が表示されます。                                         |
| 表形式  | セッション数（直近）   | 直近1ヶ月のセッション数が表示されます。                                           |
| 表形式  | 更新レコード数（直近）  | 直近1ヶ月の更新レコード数が表示されます。                                          |
| 表形式  | レコード最終更新日 | レコード最終更新日が表示されます。                                         |
| 表形式  | リンクされている     | プリザンターのリンク機能で他のテーブルからリンクされているか（マスタとして利用されているか）が「Yes」「No」で表示されます。 |
| 表形式  | サイト作成者 | サイト作成者が表示されます。                                         |
| 表形式  | サイト更新者 | サイト更新者が表示されます。                                         |
| 表形式  | サイト作成日時 | サイト作成日時が表示されます。                                         |
| 表形式  | サイト更新日時 | サイト更新日時が表示されます。                                         |
| 表形式  | 利用されていない可能性  | 上記の詳細仕様により「high」「middle」「low」で表示されます。                          |
| 表形式  | サイト管理者への削除依頼 | 「利用されていない可能性」が「high」または「middle」の場合に「削除依頼」ボタンが表示されます。           |
| 表形式  | 削除依頼日        | 「サイト管理者への削除依頼」の「削除依頼」ボタンをクリックした日時が表示されます。                      |

「サイト管理者への削除依頼」の「削除依頼」ボタンをクリックすると、対象サイトのテーブル設定の最終更新者をサイト管理者とみなし、サイト管理者宛に下記内容でメールが通知されます。

``` text
件名: 【Pleasanter運用管理】サイト削除の検討依頼

サイト管理者 様

Pleasanter運用担当者より、サイト削除の検討依頼が行われました。

以下の対象サイトにつきまして現在利用されておらず、
今後も利用予定がない場合はサイト削除のご検討をお願いします。

http://{プリザンターのパス}/items/{対象のサイトID}/edit

■ユーザマニュアル
　操作手順については、以下のユーザマニュアルをご参考にしてください。

　サイト機能：サイトを削除
　https://pleasanter.org/manual/site-delete

　サイト機能：サイトをゴミ箱から削除
　https://pleasanter.org/manual/site-delete-from-trash

■本メール案内について
　システムにより自動判定された利用されていない可能性の高いサイトに対して
　以下のような理由でサイト削除の検討をお願いしております。

　・データ容量削減のため
　・情報セキュリティリスク低減のため
　・重要な情報にたどり着きやすくするため

■連絡先
　運用担当者：<操作者の名前>
　<操作者のメールアドレス>

※本メールは送信専用です。
　問合せが必要な場合は上記の連絡先までお問い合わせください。
```

> **Note**  
> メールによる通知は、プリザンターのパラメータ設定でメールの通知設定が行われていることが前提となります。  
> 
> パラメータ設定：Mail.json | Pleasanter  
> https://pleasanter.org/manual/mail.json
