## 概要

プリザンターの利用状況詳細を月別で確認できる画面です。「開始年月」「終了年月」を指定して最長１年間をフィルタすることができます。明細情報は「年月」の昇順で表示されます。また、明細情報の「年月」のリンクをクリックすることにより、[利用状況詳細：日別](operations-tools-usage-by-day.md)の画面に遷移することができます。  

> **Note**  
> 「APIリクエスト件数」は[システムログの拡張機能](../../../managers-guide/system-log-administration/syslog-extension.md)を利用している場合のみ確認することができます。  
> 
> システムログの拡張機能 | Pleasanter  
> https://pleasanter.org/manual/syslog-extension  

![利用状況詳細の月別画面](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/bcf0579048e44df3a2ba0a3a96befc15.png)

| 表示種別 | 項目         | 説明                                                            |
|------|------------|---------------------------------------------------------------|
| 表形式  | 全般         | 「開始年月」「終了年月」でフィルタした期間内での利用状況が月別で表示されます。                       |
| 表形式  | 新規ユーザ数     | 「開始年月」「終了年月」でフィルタした期間内での新規登録されたユーザ数が表示されます。                   |
| 表形式  | アクティブユーザ数  | 「開始年月」「終了年月」でフィルタした期間内でのログインしたユーザ数が表示されます。                    |
| 表形式  | ログイン回数     | 「開始年月」「終了年月」でフィルタした期間内でのユーザのログイン回数が表示されます。                    |
| 表形式  | アクション回数    | 「開始年月」「終了年月」でフィルタした期間内でのすべてのアクション回数（Syslogsのレコード件数）が表示されます。   |
| 表形式  | メール送信件数    | 「開始年月」「終了年月」でフィルタした期間内でのメール送信件数が表示されます。                       |
| 表形式  | APIリクエスト件数 | 「開始年月」「終了年月」でフィルタした期間内でのAPIリクエスト件数が表示されます。                    |
| 表形式  | 新規レコード数    | 「開始年月」「終了年月」でフィルタした期間内での新規レコード数が表示されます。                       |
| 表形式  | 更新レコード数    | 「開始年月」「終了年月」でフィルタした期間内での更新レコード数が表示されます。                       |
| 表形式  | バイナリサイズ    | 「開始年月」「終了年月」でフィルタした期間内でのバイナリサイズ（添付ファイルや貼り付けた画像などのサイズ）が表示されます。 |
| 表形式  | 前月比率       | 前月に対しての増減が%形式で表示されます。                                         |
| グラフ  | 全般         | 「開始年月」「終了年月」でフィルタした期間内で月別に集計された結果が折れ線グラフと棒グラフの組み合わせで表示されます。   |
