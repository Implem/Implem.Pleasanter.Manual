## 概要

システムテーブルの明細情報は「システムテーブル名」を指定してフィルタすることができます。明細情報は「データ使用量（GB）」の降順、「システムテーブル名」の昇順で表示されます。  

![監視アラートのシステムテーブル画面。テーブルごとの明細情報が並ぶ](https://pleasanter.org/files/images/ja/products-info/pleasanter-extensions/operations-tools/assets/3e4feea0a8ae46af8f5b126ea3c24269.png)

| 表示種別 | 項目               | 説明                                                                     |
| -------- | ------------------ | ------------------------------------------------------------------------ |
| 表形式   | システムテーブル名 | プリザンターのシステムテーブル名（Syslogsなど）が表示されます。          |
| 表形式   | レコード件数       | プリザンターのシステムテーブルの単位でレコード件数が表示されます。       |
| 表形式   | データ使用量（GB） | プリザンターのシステムテーブルの単位でデータ使用量（GB）が表示されます。 |
