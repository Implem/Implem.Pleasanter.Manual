# リリース情報（バージョン1.1.27.0）

- 「[ユーザインターフェースのテーマをカスタマイズ](../../managers-guide/user-administration/user-management-theme.md)」する機能を追加。
- 「ルックアップ」機能を追加。
- 「読取専用の場合は画面に表示しない」設定を行う機能を追加。
- 「[フルテキストの設定](../../managers-guide/manage-table/search/fulltext-settings/index.md)」を行う機能を追加。
- サーバスクリプトにFormDataメソッドを追加。
- トップにスタイルとスクリプトを設置する機能を追加。
- リンク項目でJSON形式を使用した際にリストが取得できない問題を解消。
- リンクのSearchFormatが表示名で表示されない問題を解消。
- 検索機能を有効化した複数選択項目に$p.setが正しく動作しない問題を解消。
- サーバスクリプトのcolumnsオブジェクトのHideが一覧画面に適用されない問題を解消。
- 複数のレコードの復元が失敗する問題を解消。
- ID及びバージョン項目に不要な設定項目が表示される問題を解消。
- PostgreSQLでリマインダーの期限切れの時刻判定SQLが動作しない問題を解消。
- NetFramework関連プロジェクトを削除。

# リリース情報（バージョン1.1.26.0）

- Slackに通知できない問題を解消。
- 日付入力項目の「[時刻間隔](../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-date-time-step.md)」を設定する機能を追加。
- 「[自動ポストバック時に返却する項目](../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-columns-returned-when-automatic-postback.md)」を選択する機能を追加。
- ガントチャートの日付が横スクロール時に正しく表示されない問題を解消。
- ユーザインポート時にパスワードポリシーがチェックされない問題を解消。
- 日付の範囲フィルタで時刻を含むデータが正しく抽出できない問題を解消。
- 時刻を含まないフォーマットを指定した項目の既定値に時刻が含まれる問題を解消。
- 数値フォーマットの変換失敗時にアプリケーションエラーが発生する問題を解消。
