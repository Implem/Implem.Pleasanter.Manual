# リリース情報（バージョン1.3.39.2）

- アナウンス機能を使用している場合にリダイレクトによりログイン画面が開けない問題を解消。
- PostgreSQLの環境で「[履歴に存在するファイルは削除しない](../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-not-delete-file-with-history.md)」機能が正しく機能しない問題を解消。
- API経由でパスワードを変更する際にパスワードポリシーが正しく判定されない問題を解消。
