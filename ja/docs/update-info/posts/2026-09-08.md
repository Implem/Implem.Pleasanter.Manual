# リリース情報（バージョン1.5.8.0）

!!! warning
    9/8にリリースされた1.5.8.0のパラメータパッチに不具合があり、インストーラによるバージョンアップまたはマージ機能を利用された環境において、PasskeyParametersのOriginsパラメータの値が書き換わってしまう不具合がありました。
    9/10 18:15現在、パラメータパッチは修正版をリリース済みです。
    9/10 18:15以前にバージョンアップされた方は、大変お手数ですが設定値の見直しをお願いいたします。

    [SCIMによるユーザ同期機能を追加。](../../setup/additional/account-integration/scim/index.md)

-   [クロス集計のセルから絞り込んだ一覧へ遷移できるドリルダウン機能を追加。](../../managers-guide/manage-table/crosstab/index.md)
-   [計算式（拡張）](../../managers-guide/manage-table/formulas/table-management-formula-extended.md)に[ログインユーザのID](../../managers-guide/manage-table/formulas/formula-function-loginuserid.md)と[ログインユーザの名前](../../managers-guide/manage-table/formulas/formula-function-loginusername.md)を取得する関数を追加。
-   [Pleasanter MCPに、テンプレートを指定してサイトを作成する機能を追加。](../../ai-integration/pleasanter-mcp/index.md)
-   スクリプト、サーバスクリプト、APIに、ユーザ、組織、グループの拡張項目を取得・編集する機能を追加。

-   レコードの作成、編集APIで、添付ファイルが登録されない場合がある問題を解消。
-   テーブルの管理の変更履歴一覧でタイトルのハイパーリンクをクリックした際に、旧バージョンが表示されない問題を解消。
-   一覧の履歴表示でタイトル列が常に最新値になる問題を解消。
-   Pleasanter MCPで分類項目に対する検索実行時にデータが全件取得される問題を解消。
-   ビューの検索条件に選択不可の列を指定できる問題を解消。
-   リンク先項目を複数指定した際に値が重複する問題を解消。
-   ダッシュボードパーツのリロードボタンが表示されない問題を解消。
-   [BackgroundService.json](../../setup/parameters/background-service-json.md)のDeleteTenantデフォルト値をtrue → falseに変更。
