# リリース情報（バージョン1.3.8.0）

- ColumnFilterHashに所属グループによってフィルタする機能を追加。（[組織取得](../../developers-guide/api/department-operations/api-dept-get.md)／[ユーザ取得](../../developers-guide/api/user-operations/api-user-get.md)）
- [重複禁止の項目に任意のメッセージを設定できる機能を追加。](../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-no-duplication-message.md)
- サーバスクリプトで一覧画面の空白のセルにRawTextの内容を表示する機能を追加。
- [Security.jsonにAllowIpAddressesを追加。](../../setup/parameters/security-json.md)
- Anonymousユーザが存在する環境でユーザ情報が正しく表示できない問題を解消。
- 常に検索条件を要求するチェックがオンの場合にリンク先の一覧が表示できない問題を解消。
