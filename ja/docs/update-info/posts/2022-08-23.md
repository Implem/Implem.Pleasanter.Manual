# リリース情報（バージョン1.3.18.0）

- [否定のフィルタ条件で検索する機能を追加。](../../users-guide/table/record-authoring/data-analysis/table-record-negative-search.md)
- [サーバースクリプトのview.Filtersに項目の一致/不一致によりフィルタする機能を追加。](../../developers-guide/server-script/view/server-script-view-filters.md)
- Mail.jsonにServerCertificateValidationCallbackパラメータを追加。
- ルックアップのOverwriteFromがtrueの場合にフォームからの直接入力が無視される問題を解消。
- リンク削除時にリンク情報のキャッシュが正しく更新されない問題を解消。
- 分類項目のフルテキストの種類に指定した値が正しく動作しない問題を解消。
- UTC環境でリマインダーがエラーで動作しない問題を解消。
- リンク表示の位置を変更している場合、レコードが存在しない場合に空のリンク領域が表示される問題を解消。
