# Pleasanter Code Assistリリース情報（バージョン1.3.0）

-   **【重要】保存と同期の動作を分離。**  
    詳細は「[コマンドおよび設定項目](../../products-info/pleasanter-extensions/pleasanter-code-assist/pleasanter-code-assist-feature.md)」の[PCA: Save and Sync](../../products-info/pleasanter-extensions/pleasanter-code-assist/pleasanter-code-assist-feature.md#pca-save-and-sync)を参照。
-   `scripts`や`serverscripts`などのフォルダ内にサブフォルダを作成し、作成したスクリプトを整理・分類して保存できる機能を追加。  
    詳細は「[使い方：拡張機能](../../products-info/pleasanter-extensions/pleasanter-code-assist/pleasanter-code-assist-how-to-use-extensions.md)」と「[使い方：サイト](../../products-info/pleasanter-extensions/pleasanter-code-assist/pleasanter-code-assist-how-to-use-sites.md)」を参照。
-   ファイル名に使用できる変数（`${psFileBasename}`、`${psFileBasenameNoExt}`、`${psFileExtname}`）が、ファイル内に複数存在する場合に正しく置換されない問題を解消。
-   ファイル名自体に`$`記号が含まれる場合に、変数の置換処理が誤動作する問題を解消。
-   HTTPS接続時のTLS証明書検証が特定の環境で正しく機能しない問題を解消。
-   Visual Studio Code（Electron）環境でaxiosがブラウザモードと誤判定し、httpsAgentのTLS設定が無視される問題を解消。
