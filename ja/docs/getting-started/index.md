## 概要

いますぐプリザンターを試してみたい人向けのセットアップガイドです。ここでは3つの方法を紹介します。

| 方法                                         | セットアップ | 使える期間 | サンプルデータ | 機能制限 |
| :------------------------------------------- | :----------: | :--------: | :------------: | :------: |
| :one: デモ環境ではじめる                     |     不要     |   60日間   |      あり      |   あり   |
| :two: Dockerではじめる                       |     必要     |   ずっと   |      なし      |   なし   |
| :three: Pleasanter.netフリープランではじめる |     不要     |   ずっと   |      なし      |   あり   |

以下では、技術的な詳細をできる限り省き、手順だけをまとめています。

## :one: デモ環境ではじめる

デモ環境では、セットアップの手間なしで、サンプルデータ付きのプリザンターを、手軽に試せます。  
デモ環境の利用方法は以下のPDFを参照してください。

[PDFを読む](https://pleasanter.org/downloads/get-started-pleasanter.pdf){ .md-button }

## :two: Dockerではじめる

Dockerを使ってセットアップすると、機能制限のないプリザンター（Community Edition）をずっと使えます。  
手順は、以下の「説明を読む」をクリックしてください。

[説明を読む](getting-started-with-docker.md){ .md-button }

## :three: Pleasanter.netフリープランではじめる

Pleasanter.netフリープランでは、セットアップの手間なしで、プリザンターをずっと使えます。  
Pleasanter.netフリープランの利用方法は以下のPDFを参照してください。

[PDFを読む](https://pleasanter.org/downloads/pleasanter_net_start.pdf){ .md-button }
