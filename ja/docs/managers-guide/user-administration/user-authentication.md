## 概要

プリザンターでは、ユーザ認証として次の方式を利用できます。

-   ローカルユーザのID・Passwordによる認証
-   Active DirectoryなどLDAPによる認証

ローカルユーザでID・Passwordにより認証するには、ユーザ管理機能で新規ユーザを作成します。

-   [ユーザ管理機能：作成・更新](user-new-edit.md)

Active DirectoryにログインしたWindows端末を利用するとシングルサインオンを実現できます。
