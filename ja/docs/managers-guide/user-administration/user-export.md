## 概要

[ユーザ管理](index.md)画面のユーザ情報をCSVファイルとして出力するための機能です。現在のユーザ情報を一括で取得できます。

## 手順

1.  [ユーザ管理](index.md)画面にて画面下の[エクスポート](../../developers-guide/api/table-operations/api-export.md)ボタンをクリックします。
1.  エクスポートダイアログが表示されます。書式、文字コードを選択します。書式は"標準"のみ選択可能です。文字コードはShift-JISまたはUTF-8が選択できます。
1.  CSVファイルがダウンロードされます。エクスポートされる項目については、下記「CSVファイル項目名」を参照ください。

## CSVファイル項目名

| 項目名(エクスポートされる列名) | 説明                                                                     |
| :----------------------------- | :----------------------------------------------------------------------- |
| ユーザID                       | 対象ユーザのID                                                           |
| ログインID                     | システムにログインするためのID                                           |
| 名前                           | ユーザの名前                                                             |
| コメント                       | 「レコード」のコメント                                                   |
| ユーザコード                   | 対象ユーザのユーザコード                                                 |
| 言語                           | ログインユーザが使用する言語                                             |
| タイムゾーン                   | システム時刻を計算するために使用されるタイムゾーン                       |
| 組織コード                     | 組織を管理するためのコード                                               |
| 組織                           | ユーザの所属する組織                                                     |
| 管理者                         | 上長や承認者など対象ユーザに関連するユーザ                               |
| テーマ                         | 画面のユーザインターフェース                                             |
| 説明                           | 対象ユーザに対する説明                                                   |
| 最終ログイン日時               | 対象ユーザが最終ログインした日時                                         |
| パスワード有効期限             | 対象ユーザのログインパスワードの有効期限                                 |
| パスワード変更日時             | 対象ユーザのログインパスワードを変更した日時                             |
| ログイン回数                   | 対象ユーザがログインした回数                                             |
| ログイン失敗回数               | 対象ユーザがログインを失敗した回数                                       |
| テナント管理者                 | システム管理者としての権限                                               |
| サイトトップへの作成を許可     | サイトトップへの作成許可権限                                             |
| サイトトップからの移動を許可   | サイトトップからの移動許可権限                                           |
| グループの管理を許可           | グループの管理許可権限                                                   |
| グループの作成を許可           | グループの作成許可権限                                                   |
| APIを許可                      | APIの許可権限                                                            |
| 2段階認証の有効化              | 2段階認証の有効化設定                                                    |
| 2段階認証の無効化              | 2段階認証の無効化設定                                                    |
| 秘密鍵有効                     | TOTP認証の連携有無設定                                                   |
| 無効                           | ユーザのログイン有効化/無効                                              |
| ロック                         | ユーザのログイン有効化/無効                                              |
| ロックカウンター               | 対象ユーザのログイン失敗回数                                             |
| ログイン有効期限               | 対象ユーザがログインできる期限                                           |
| 無効化までの日数               | 最終ログイン日時から設定した日数ログインしなかった場合にログインNGとする |
| 作成者                         | 「レコード」の作成者                                                     |
| 更新者                         | 「レコード」の更新者                                                     |
| 更新日時                       | 「レコード」の更新日時                                                   |
| メールアドレス                 | 対象ユーザのメールアドレス                                               |
| パスワード                     | 空白で出力                                                               |

## 制限事項

-   テーブルの一覧のエクスポートとは違い、チェックボックスの有/無にかかわらず全件データが対象となります。
-   [ユーザ管理](index.md)画面での表示項目の他に、メールアドレスをエクスポートします。 
-   「パスワード」は、セキュリティの為空白で出力されます。
