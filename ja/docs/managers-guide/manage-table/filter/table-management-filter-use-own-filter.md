## 概要

[一覧画面](../../../users-guide/table/record-authoring/data-analysis/table-grid.md)で「管理者」項目または「担当者」項目が「自分」のレコードのみを一覧に表示するためのフィルタ機能を表示する場合にオンに設定します。記録テーブル、期限付きテーブルで設定することができます。

## 前提条件

1. 設定を行うには「サイトの管理権限」が必要です。

## 設定方法

1. テーブルの管理からフィルタタブを選択し、下図のように「自分フィルタを使用する」にチェックをオンに設定すると一覧画面のフィルタに表示されます。またチェックをオフに設定すると一覧画面でのフィルタに表示されなくなります。

![テーブルの管理のフィルタタブにある「自分フィルタを使用する」のチェック](https://pleasanter.org/files/images/ja/managers-guide/manage-table/filter/assets/95da1cb22a3b47eba45a47c8aa83ccf1.png)

## 動作イメージ

オンの場合
![オンのとき、一覧画面のフィルタに「自分」が表示された状態](https://pleasanter.org/files/images/ja/managers-guide/manage-table/filter/assets/2d5a41b80a894c75829e0772a12ff1d0.png)

オフの場合
![オフのとき、一覧画面のフィルタに「自分」が表示されない状態](https://pleasanter.org/files/images/ja/managers-guide/manage-table/filter/assets/a46d37477bcb4a0fb6fbeb4910368d23.png)
