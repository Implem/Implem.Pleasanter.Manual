## 概要

[項目](../../editor/editor-settings/columns/index.md)の文字列を検索する際の検索方式として「部分一致」、「完全一致」、「前方一致」を選択します。

## 制限事項

1. [タイトル項目](../../editor/editor-settings/columns/table-management-title.md)、[内容項目](../../editor/editor-settings/columns/table-management-body.md)、[分類項目](../../editor/editor-settings/columns/table-management-class.md)、[説明項目](../../editor/editor-settings/columns/table-management-description.md)のみ使用できます。

## 前提条件

1. 設定を行うには「サイトの管理権限」が必要です。

## 設定内容

|No|設定項目|説明|
|:----|:----|:----|
|1|部分一致|文字列の一部分がヒットした場合にレコードを抽出します。アルファベットの大文字/小文字は区別されません。|
|2|完全一致|文字列が一致した場合にレコードを抽出します。アルファベットの大文字/小文字は区別されません。|
|3|前方一致|文字列の先頭の一部がヒットした場合にレコードを抽出します。アルファベットの大文字/小文字は区別されません。|
