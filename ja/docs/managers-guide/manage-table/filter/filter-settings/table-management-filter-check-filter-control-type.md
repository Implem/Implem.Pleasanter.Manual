## 概要

[チェック項目](../../editor/editor-settings/columns/table-management-check.md)の[フィルタ](../../../../users-guide/hands-on/advanced/advanced-operations-link.md)で「オン」のみを検索するコントロールと、「オン」または「オフ」を検索するコントロールを切り替えます。

## 制限事項

1. [チェック項目](../../editor/editor-settings/columns/table-management-check.md)のみ使用できます。

## 前提条件

1. 設定を行うには「サイトの管理権限」が必要です。

## 設定内容

|No|選択肢|説明|
|:----|:----|:----|
|1|オンのみ|[フィルタ](../../../../users-guide/hands-on/advanced/advanced-operations-link.md)に「チェックボックス」が表示され、チェックを行うと値が「オン」のレコードを抽出します。操作は1クリックで行えますが値が「オフ」のレコードは抽出できません。|
|2|オンとオフ|[フィルタ](../../../../users-guide/hands-on/advanced/advanced-operations-link.md)に「セレクトボックス」が表示され、「オン」を選択すると値が「オン」のレコードを抽出します。「オフ」を選択すると値が「オフ」のレコードを抽出します。|
