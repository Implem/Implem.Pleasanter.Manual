## 概要

レコード作成後の動作を設定します。

## 前提条件

「サイトの管理」権限

## 操作手順

1.  対象の[テーブル](../../../../users-guide/table/index.md)を開いてください。
1.  「管理」メニューから[テーブルの管理](../../index.md)をクリックしてください。
1.  [エディタ](../../../../users-guide/table/record-authoring/edit-records/table-editor.md)タブを開いてください。
1.  画面下部にある「作成後の動作」のドロップダウンリストから任意の設定を選択してください。

    ![エディタタブ下部の「作成後の動作」ドロップダウンリスト](https://pleasanter.org/files/images/ja/managers-guide/manage-table/editor/after-create-action/assets/64e5c0012032455b80e620280137ef1b.png)

1.  画面下部の「更新」ボタンをクリックしてください。

## 設定内容

| 選択肢             | 説明                                         |
| :----------------- | :------------------------------------------- |
| （空欄）           | 既定の設定。作成したレコードを編集画面で表示 |
| 一覧画面に戻る     | 一覧画面を表示                               |
| 新規作成画面を開く | 新規作成画面を表示                           |

## 対応バージョン

| 対応バージョン | 内容     |
| :------------- | :------- |
| 1.4.23.0 以降  | 機能追加 |
