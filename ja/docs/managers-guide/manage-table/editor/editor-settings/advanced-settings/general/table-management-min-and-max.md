## 概要

[数値項目](../../columns/table-management-num.md)の最小値と最大値を制限する場合、[コントロール種別](table-management-control-type.md)で「スピナー」を使用する場合の「ステップ」を指定します。

## 制限事項

1.  [数値項目](../../columns/table-management-num.md)でのみ設定できます。
1.  「最小」は「-999999999999999」より小さくすることはできません。
1.  「最大」は「999999999999999」より大きくすることはできません。
1.  「ステップ」は[コントロール種別](table-management-control-type.md)で「スピナー」を選択した場合のみ使用できます。
1.  「ステップ」は「最小」で指定した数値を基準に数値の加減算が行われます。「ステップ」に 2 以上の数値を指定する場合に「最小」は「ステップ」の倍数を指定するようにしてください。

## 前提条件

1.  設定を行うには「サイトの管理権限」が必要です。

## 使用例

### 1. 「最小、最大、ステップ」のデフォルト値で「スピナー」を使用する際の動き

#### 「数値A」の詳細設定

| 内容             | 値               |
| :--------------- | :--------------- |
| 既定値           | 0                |
| コントロール種別 | スピナー         |
| 最小             | -999999999999999 |
| 最大             | 999999999999999  |
| ステップ         | 1                |

#### 「数値A」の編集画面の動き

| 内容                     | 「数値A」の増減                     |
| :----------------------- | :---------------------------------- |
| 初期値から増やす際の動き | 0 → 1 → 2 → 3 … 999999999999999     |
| 初期値から減らす際の動き | 0 → -1 → -2 → -3 … -999999999999999 |

### 2. 正の数のみ入力する場合

#### 「数値A」の詳細設定

| 内容             | 値              |
| :--------------- | :-------------- |
| 既定値           | 1               |
| コントロール種別 | スピナー        |
| 最小             | 1               |
| 最大             | 999999999999999 |
| ステップ         | 1               |

#### 「数値A」の編集画面の動き

| 内容                     | 「数値A」の増減                   |
| :----------------------- | :-------------------------------- |
| 初期値から増やす際の動き | 1 → 2 → 3 → 4 … 999999999999999   |
| 初期値から減らす際の動き | 1より小さい数値に減らすことは不可 |

### 3. 0と5の倍数のみ入力する場合

#### 「数値A」の詳細設定

| 内容             | 値               |
| :--------------- | :--------------- |
| 既定値           | 0                |
| コントロール種別 | スピナー         |
| 最小             | -999999999999995 |
| 最大             | 999999999999995  |
| ステップ         | 5                |

#### 「数値A」の編集画面の動き

| 内容                     | 「数値A」の増減                       |
| :----------------------- | :------------------------------------ |
| 初期値から増やす際の動き | 0 → 5 → 10 → 15 … 999999999999995     |
| 初期値から減らす際の動き | 0 → -5 → -10 → -15 … -999999999999995 |

「最小」に「ステップ」の倍数を指定します。上記、制限事項5の記載通り「最小」で指定した「-999999999999995」を基準に、「ステップ」で指定した「5」ずつ加減算をした結果が「数値A」に設定されます。「最小」に5の倍数以外を指定すると、「数値A」に5の倍数は設定されず、一度数値を増減した後で既定値の0に戻すこともできなくなるため注意してください。

### 4. 正の数かつ5の倍数のみ入力する場合

#### 「数値A」の詳細設定

| 内容             | 値              |
| :--------------- | :-------------- |
| 既定値           | 5               |
| コントロール種別 | スピナー        |
| 最小             | 5               |
| 最大             | 999999999999995 |
| ステップ         | 5               |

#### 「数値A」の編集画面の動き

| 内容                     | 「数値A」の増減                    |
| :----------------------- | :--------------------------------- |
| 初期値から増やす際の動き | 5 → 10 → 15 → 20 … 999999999999995 |
| 初期値から減らす際の動き | 5より小さい数値に減らすことは不可  |
