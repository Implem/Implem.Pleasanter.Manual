## 概要

[選択肢一覧](index.md)に[組織](../../../../../../department-administration/index.md)の一覧を設定します。

## 制限事項

-   [分類項目](../../../columns/table-management-class.md)以外では使用できません。

## 前提条件

-   設定を行うには「サイトの管理権限」が必要です。

## 記述例

[組織](../../../../../../department-administration/index.md)の一覧を表示するための記述例です。すべての[組織](../../../../../../department-administration/index.md)がリストされます。

``` text title="選択肢一覧"
[[Depts]]
```
