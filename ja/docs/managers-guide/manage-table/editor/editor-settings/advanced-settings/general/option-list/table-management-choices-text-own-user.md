## 概要

[選択肢一覧](index.md)に[ユーザ](table-management-choices-text-users.md)の一覧を設定している項目で、クリック時にログインユーザを設定できます。

## 制限事項

-   [担当者項目](../../../columns/table-management-owner.md)、[管理者項目](../../../columns/table-management-manager.md)、[分類項目](../../../columns/table-management-class.md)以外では使用できません。

## 前提条件

-   設定を行うには「サイト管理権限」が必要です。

## 記述例

記述例は、[ユーザの選択肢一覧](table-management-choices-text-users.md)を参照してください。

## 画面例

[担当者項目](../../../columns/table-management-owner.md)、[管理者項目](../../../columns/table-management-manager.md)、項目の選択肢一覧に[[Users]]を設定している分類項目は、入力項目横にアイコンが表示されます。このアイコンを選択するとログインユーザを入力項目に設定します。

![入力項目の横に表示されるログインユーザ設定ボタンのアイコン](https://pleasanter.org/files/images/ja/managers-guide/manage-table/editor/editor-settings/advanced-settings/general/option-list/assets/2d97e0d998a4461ab48ddc0cad188ca2.png)
