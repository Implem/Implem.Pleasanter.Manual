## 概要

[一覧画面](../../../users-guide/table/record-authoring/data-analysis/table-grid.md)のカスタマイズを行うことができます。[一覧画面の項目の設定](table-management-grid-columns.md)、[既定のビュー](table-management-default-view.md)、[一覧編集種別](table-management-grid-editor-type.md)など様々な設定をカスタマイズします。

## 前提条件

1. 設定を行うには「サイトの管理権限」が必要です。
