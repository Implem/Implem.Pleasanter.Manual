## 概要

0以上で1より小さい実数の乱数を返します。計算するたびに新しい乱数を返します。

## 構文

```
$RAND()  
```

## パラメータ

なし

## 戻り値

0以上1未満の実数

### 戻り値の表示内容

|対象|戻り値の表示内容|
|:---|:---|
|分類（タイトル、状況、管理者、担当者含む）|戻り値を表示。|
|数値（作業量、進捗率、残作業量含む）|戻り値を表示。|
|日付（開始、完了含む ）|表示しない。|
|説明（内容含む）|戻り値を表示。|
|チェック（ロック含む）|表示しない。|
