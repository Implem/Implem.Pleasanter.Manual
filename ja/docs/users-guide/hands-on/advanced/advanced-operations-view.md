## 概要

「ビュー」は利用ユーザごとに一覧で表示したい項目を切り替えたり、よく使うフィルタ条件やソート順を登録しておくことができる機能です。またサマリや通知の条件としても利用できます。

## 設定項目

ビューの設定画面では主に以下のよう内容を設定できます。

| タブ名         | 説明                                                                                                                                                                                                                                                                                             |
| :------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 一覧           | 一覧画面での表示項目の設定、[フィルタと集計の設定](../../../managers-guide/manage-table/view/table-management-view-filter-totaling.md)、[コマンドボタンの設定](../../../managers-guide/manage-table/view/table-management-view-command-button.md)。                                              |
| フィルタ       | ビューに表示されるレコードの検索（フィルタ）の設定。表示するフィルタ項目の設定と合わせてあらかじめフィルタ条件を指定できます。                                                                                                                                                                   |
| ソータ         | ビューに表示されるレコードの並び替え（ソート）の設定。複数項目のソート順を設定できます。                                                                                                                                                                                                         |
| エディタ       | レコードのエディタ画面に表示されるボタンの設定。[エディタ](../../table/record-authoring/edit-records/table-editor.md)や[サイトのアクセス制御](../../../managers-guide/manage-table/site-access-control/index.md)での設定結果で表示するボタンに対して更に制御することができます。 |
| カレンダー     | ビューをカレンダー表示した場合の設定。分類、期間、項目の初期値を設定できます。                                                                                                                                                                                                                   |
| クロス集計     | ビューをクロス集計表示した場合の設定。列・行の分類、集計種別、集計対象等の初期値を設定できます。                                                                                                                                                                                                 |
| ガントチャート | ビューをガントチャート表示した場合の設定。分類、ソートの初期値を設定できます。                                                                                                                                                                                                                   |
| 時系列チャート | ビューを時系列チャート表示した場合の設定。分類、集計種別、集計対象の初期値を設定できます。                                                                                                                                                                                                       |
| カンバン       | ビューをカンバン表示した場合の設定。列・行の分類、集計種別、集計対象等の初期値を設定できます。                                                                                                                                                                                                   |
| アクセス制御   | ビューに対する[アクセス制御の設定](../../../managers-guide/manage-table/view/table-management-view-permissions.md)。利用可能なユーザ・組織・グループを設定できます。                                                                                                                             |

## 条件としての利用

以下の 設定に対する条件として利用できます。ここで利用するビューには[フィルタ](advanced-operations-link.md)を設定してください。

| 設定項目（タブ名） | 説明                                                                                                                                                                                                                                                                                                                                                                             |
| :----------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| サマリ             | データ保存先および自テーブルのサマリする際の条件。データ保存先の条件で指定した「ビュー」の[フィルタ](advanced-operations-link.md)に合致する「親レコード」に対して[サマリ](advanced-operations-link.md)します。自テーブルの条件で指定した「ビュー」の[フィルタ](advanced-operations-link.md)に合致する「子レコード」が[サマリ](advanced-operations-link.md)の集計対象となります。 |
| 計算式             | 計算式を実行する際の条件。条件で指定した「ビュー」の[フィルタ](advanced-operations-link.md)に合致するレコードに対して計算式を実行します。                                                                                                                                                                                                                                        |
| 通知               | 変更前、変更後の条件。変更前の条件で指定した「ビュー」の[フィルタ](advanced-operations-link.md)に合致するレコードおよび、変更後の条件で指定した「ビュー」の[フィルタ](advanced-operations-link.md)に合致するレコードが通知の対象となります。変更前の条件、変更後の条件は論理式（And／Or）で組み合わせることができます。                                                          |
| リマインダー       | リマインダー対象とする際の条件。条件で指定した「ビュー」の[フィルタ](advanced-operations-link.md)に合致する「親レコード」に対してリマインドを通知します。                                                                                                                                                                                                                        |
