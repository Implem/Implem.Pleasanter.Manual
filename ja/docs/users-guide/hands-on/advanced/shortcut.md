## 概要

### プリザンターで利用可能なショートカットキー

プリザンターのキーボード操作の支援を目的としたショートカットキーの説明です。

| 操作                                                                                         | ショートカットキー | 新規作成画面 | 編集画面 | 一覧画面 | サイト設定画面 |
| -------------------------------------------------------------------------------------------- | ------------------ | ------------ | -------- | -------- | -------------- |
| サイトメニューで上位の画面に戻る                                                             | ++alt+q++          | -            | -        | -        | -              |
| 「戻る」ボタンを押す                                                                         | ++alt+q++          | ○            | ○        | ○        | ○              |
| 「作成」ボタンを押す                                                                         | ++alt+s++          | ○            | -        | -        | -              |
| 「更新」ボタンを押す                                                                         | ++alt+s++          | -            | ○        | -        | ○              |
| [コピー](advanced-operations-copy.md)ボタンを押す                                            | ++alt+c++          | -            | ○        | -        | ○              |
| [参照コピー](advanced-operations-copy.md)ボタンを押す                                        | ++alt+k++          | -            | ○        | -        | -              |
| [移動](../../table/record-authoring/edit-records/table-record-move.md)ボタンを押す           | ++alt+o++          | -            | ○        | -        | -              |
