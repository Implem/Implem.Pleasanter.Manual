## 1. フォルダを作成する

はじめに、トップ画面へフォルダを作成してください。

フォルダは、テーブルを階層的に整理するためだけでなく、テーブルに対するアクセス権をまとめて管理するためにも利用可能です。

!!! tip
    最初にフォルダを作成し、その中でテーブルの作成を行うことをお勧めします。

:material-arrow-right:
[フォルダ作成](basic-operations-folder.md)

## 2. テーブルを作成する

次に、作成したフォルダ内にテーブルを追加します。

テーブルには[記録テーブル](../../table/index.md)と[期限付きテーブル](../../table/index.md)の2つのタイプがあります。

### 記録テーブル

表形式でデータを記録するための機能です。

### 期限付きテーブル

タスク管理など期限を管理するための機能です。記録テーブルの[項目](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-column.md)に加え、以下の項目が用意されています。

-   [完了](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-completion-time.md)：レコードの期限を設定します。
-   [作業量](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-work-value.md)：レコードに紐づく作業の工数を入力します。
-   [進捗率](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-progress-rate.md)：作業の進捗状況をパーセンテージで記録します。
-   [残作業量](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-remaining-work-value.md)：作業量と進捗率から、残りの作業量から計算した値が自動で入力されます。

!!! tip
    上記以外にも、メモやリンク集などを記録するための[Wiki](../../wiki/index.md)という機能もあります。

:material-arrow-right:
[テーブル作成](basic-operations-table.md)

## 3. 編集画面の項目を追加する

テーブルを作成した後は、登録するデータに合わせてテーブルの項目（カラム）をカスタマイズします。

まず、レコードの「新規作成」画面や、「編集」画面で入力可能な項目を設定します。

:material-arrow-right:
[編集画面の項目追加](basic-operations-editor.md)

## 4. 一覧画面に表示する項目を追加する

入力可能な項目を設定しただけでは、その項目は表示されません。レコード一覧画面に表示されるように設定します。

:material-arrow-right:
[一覧画面の項目追加](basic-operations-grid.md)
