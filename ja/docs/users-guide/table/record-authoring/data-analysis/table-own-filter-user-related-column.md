## 概要

[担当者項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-owner.md)、[管理者項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-manager.md)、[分類項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-class.md)の[フィルタ](../../../hands-on/advanced/advanced-operations-link.md)で「自分」を選択する機能について説明します。

## 制限事項

1. [担当者項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-owner.md)、[管理者項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-manager.md)などのユーザ項目や[組織の選択肢一覧](../../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/option-list/table-management-choices-text-depts.md)または[ユーザの選択肢一覧](../../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/option-list/table-management-choices-text-users.md)を設定している[分類項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-class.md)で使用できます。[グループの選択肢一覧](../../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/option-list/table-management-choices-text-groups.md)を設定している[分類項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-class.md)では使用できません。
2. [分類項目](../../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-class.md)の[複数選択](../../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-multiple-selections.md)を有効化している場合、フィルタ機能が動作しません。

## 操作手順

1. 対象のテーブルに移動します。
1. [一覧画面](table-grid.md)の[フィルタ](../../../hands-on/advanced/advanced-operations-link.md)から対象の項目をクリックします。
1. 「自分」を選択します。

### 分類項目で組織の選択肢一覧を設定している場合

ログインユーザーが所属する組織でフィルタされます。  
![組織の選択肢で「自分」を選んだときのフィルタの表示](https://pleasanter.org/files/images/ja/users-guide/table/record-authoring/data-analysis/assets/83946950e6ab46b88deffac8563f3eae.png)

### 分類項目でユーザの選択肢一覧を設定している場合

ログインユーザでフィルタされます。  
![ユーザの選択肢で「自分」を選んだときのフィルタの表示](https://pleasanter.org/files/images/ja/users-guide/table/record-authoring/data-analysis/assets/67177b9ae76947ba8714d8a072c1237c.png)

### 分類項目で検索機能を使う場合

検索ダイアログで「自分」を選択することが可能です。  
![「自分」を選択できる検索ダイアログ](https://pleasanter.org/files/images/ja/users-guide/table/record-authoring/data-analysis/assets/af0e7caff8a845acb2c7da879653c1ea.png)

テーブルの一覧画面の[フィルタ](../../../hands-on/advanced/advanced-operations-link.md)機能だけでなく、テーブルの管理画面における[ビュー](../../../hands-on/advanced/advanced-operations-view.md)や[プロセス](../../../hands-on/advanced/advanced-operations-process.md)機能で条件として指定することも可能です。
