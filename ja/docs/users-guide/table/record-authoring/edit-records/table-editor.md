## 概要

[テーブル](../../index.md)に格納された特定の「レコード」を単票形式で表示します。権限がある場合には[レコードの更新](table-record-edit.md)や「[レコードの削除](table-record-delete.md)」等の操作を行うことができます。「エディタ」の「入力項目」等の設定を変更するには[テーブルの管理](../../../../managers-guide/manage-table/index.md)を使用してください。

## 前提条件

1. [レコードの閲覧](table-record-edit.md)を行うには読取り権限が必要です。
