## 概要

ダッシュボードパーツのレイアウトなど、ダッシュボードの表示状態の保存方法を設定します。

## 前提条件

1.  この設定を行うには「サイトの管理権限」が必要です。

## 操作手順

1.  対象の[ダッシュボード](dashboard-add-parts.md)を開いてください。
1.  「管理」メニューから「ダッシュボードの管理」をクリックしてください。
1.  [ビュー](../hands-on/advanced/advanced-operations-view.md)タブをクリックしてください。
1.  「ビューの保存種別」のドロップダウンから設定値を選択してください。

    ![ダッシュボードの管理のビュータブにある「ビューの保存種別」のドロップダウン](https://pleasanter.org/files/images/ja/users-guide/dashboard/assets/e58f6e07b3324a9db06824c8480d6696.png)

### ビューの保存種別

| ビューの保存種別 | 説明                                                                                                                                     |
| :--------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| セッション       | 次の条件で保持されます。(1)プリザンターからログアウトするまで (2)Session.jsonのRetentionPeriodの値の期限内 (3)全てのブラウザを閉じるまで |
| ユーザ           | データベースに保存し、次回も適用されます                                                                                                 |
| 保存しない       | ビューの状態は保存されず、常に初期状態で表示します。                                                                                     |

### ビューに保存される内容

ビューに保存される内容は次の通りです。

-   ダッシュボードパーツの表示位置および幅、高さ
-   カレンダーの表示状態（基準日、月表示／週表示など）
