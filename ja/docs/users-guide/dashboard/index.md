## 概要

各アプリでの新着情報やお知らせや掲示板、作成したアプリへのリンクの他に他サイトの表示など必要な情報を一覧で表示する機能です。

![複数のパーツを並べたダッシュボードの画面](https://pleasanter.org/files/images/ja/users-guide/dashboard/assets/37b24e5420f94388a577b9511957837d.png)

## 利用方法

ダッシュボードの利用における手順は下記の通りです。

1.  ダッシュボードを作成する
1.  ダッシュボードにパーツを追加する
1.  必要に応じてダッシュボードをトップ画面に設定する

## ダッシュボードの作成

ダッシュボードは[サイト機能](../site/index.md)と同様の手順で操作することができます。作成数に上限はありません。

詳細は下記を参照してください。  
[ダッシュボード作成 | Pleasanter](../hands-on/basics/basic-operations-dashboard.md)

## パーツの追加

「ダッシュボードの管理」にてパーツの追加を行います。追加できるパーツは下記の通りです。

| パーツ           | 機能                                                                                                                                                                                                                  | 主な用途                                         |
| :--------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------- |
| クイックアクセス | フォルダやテーブルへのリンクを表示します。                                                                                                                                                                            | 各サイト、テーブルへのショートカットメニュー     |
| タイムライン     | 指定したテーブル内のレコードを表示します。表示するレコードのフィルタや表示順の指定が可能です。                                                                                                                        | 割り当てタスクや掲示板の新着表示                 |
| カスタム         | 指定したテキストを表示します。[マークダウン](../common/markdown.md)を使用した入力や[画像](../table/record-authoring/edit-records/table-record-upload-picture.md)の貼り付けが可能です。                                | 使い方やヘルプなど文章の表示                     |
| カスタムHTML     | 指定したHTMLの内容を表示します。[スクリプト](../../managers-guide/manage-table/scripts/index.md)、[スタイル](../../developers-guide/style/index.md)と組み合わせることで、様々な用途に拡張可能です。 | グラフチャート、動画、地図、カレンダーの埋め込み |
| カレンダー       | カレンダーを表示します。複数テーブルの予定をまとめて表示することが可能です。                                                                                                                                          | ダッシュボード上での予定の確認                   |
| カンバン         | カンバンを表示します。ダッシュボード上でドラッグアンドドロップによるアイテムの移動が可能です。                                                                                                                        | ダッシュボード上での担当者、状況などの更新       |
| 一覧             | レコードの一覧を表示します。複数テーブルのレコードをまとめて表示することが可能です。                                                                                                                                  | ダッシュボード上でのレコードの確認               |

## トップ画面に設定

[テナントの管理](../../managers-guide/tenant-administration/index.md)にて作成したダッシュボードをトップ画面に設定することができます。ダッシュボードを複数作成している場合はそのうち1つを設定します。

![ダッシュボードをトップ画面に設定する画面](https://pleasanter.org/files/images/ja/users-guide/dashboard/assets/01c67d24ae0046178927955b8af15c02.png)
