## 概要

[スマートデザイン](smart-design-editor.md)での「リンクテーブル」について説明します。[リンク](../../hands-on/advanced/advanced-operations-link.md)の詳細は以下ページを参照ください。  
[テーブルの管理：エディタ：項目の詳細設定：選択肢一覧：リンク](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/option-list/table-management-choices-text-link.md)

## リンクテーブルカードの説明

![リンクテーブルカード。各部に番号を振った図](https://pleasanter.org/files/images/ja/users-guide/smart-design/editor/assets/29e0ecaecdae4746ad0557c8f2966d5c.png)

|No|タグ|説明|
|:--:|:--|:--|
|1|表示名|配置された項目の表示名です。|
|2|ゴミ箱アイコン|リンクテーブルをエディタから無効化する際のボタンです。|
|3|タグ|一部の設定のオプション値を表示します。詳しくは下記のタグ一覧を確認してください。|

### タグ一覧

|タグ|説明|
|:--:|:--|
|リンクテーブル|カードがリンクテーブルであることを表します。|
|リンク先:SiteId|リンク先のサイトIDを表示します。|
|リンク元:SiteId|リンク元のサイトIDを表示します。|

### リンクテーブルの削除

No.2のゴミ箱アイコンをクリックし、ダイアログの削除ボタンから無効化が可能です。
![リンクテーブルを削除するダイアログ](https://pleasanter.org/files/images/ja/users-guide/smart-design/editor/assets/3b58ef694bd1421fb648ecdced217b7c.png)
