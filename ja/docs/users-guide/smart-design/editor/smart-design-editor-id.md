## 概要

[スマートデザイン](smart-design-editor.md)での[ID](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-id.md)の項目編集ダイアログについて説明します。[ID項目](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-id.md)の詳細は以下ページを参照ください。  
[テーブルの管理：項目：ID](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-id.md)

## 設定内容

![スマートデザインの「ID」項目編集ダイアログ](https://pleasanter.org/files/images/ja/users-guide/smart-design/editor/assets/bfaf1282218b495ba6cf1351d1dc17dd.png)

|項目|概要|備考|
|---|---|---|
|表示名|項目のラベルとして表示する文字列を設定|詳細は[テーブルの管理：エディタ：項目の詳細設定：表示名](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-label-text.md)を参照ください|
|配置|項目の内容の水平方向の配置（左寄せ、または右寄せ）を設定|詳細は[テーブルの管理：エディタ：項目の詳細設定：配置](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-textalign.md)を参照ください|
|スタイル|入力項目のスタイル（ノーマル、ワイド）を設定|詳細は[テーブルの管理：エディタ：項目の詳細設定：入力項目のスタイル](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-field-css.md)を参照ください|
