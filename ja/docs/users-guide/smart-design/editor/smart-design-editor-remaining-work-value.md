## 概要

[スマートデザイン](smart-design-editor.md)での「[残作業量](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-remaining-work-value.md)」の項目編集ダイアログについて説明します。[残作業量項目](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-remaining-work-value.md)の詳細は以下ページを参照ください。  
[テーブルの管理：項目：残作業量](../../../managers-guide/manage-table/editor/editor-settings/columns/table-management-remaining-work-value.md)

## 設定内容

![スマートデザインの「残作業量」項目編集ダイアログ](https://pleasanter.org/files/images/ja/users-guide/smart-design/editor/assets/bb43a838eb184315a8f9bf2d2bb0c010.png)

|項目|概要|備考|
|---|---|---|
|表示名|項目のラベルとして表示する文字列を設定|詳細は[テーブルの管理：エディタ：項目の詳細設定：表示名](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-label-text.md)を参照ください|
|配置|項目の内容の水平方向の配置（左寄せ、または右寄せ）を設定|詳細は[テーブルの管理：エディタ：項目の詳細設定：配置](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-textalign.md)を参照ください|
|スタイル|入力項目のスタイル（ノーマル、ワイド）を設定|詳細は[テーブルの管理：エディタ：項目の詳細設定：入力項目のスタイル](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-field-css.md)を参照ください|
|単位|数値項目に単位を付けて表記したい文字列を設定|詳細は[テーブルの管理：エディタ：項目の詳細設定：単位](../../../managers-guide/manage-table/editor/editor-settings/advanced-settings/general/table-management-unit.md)を参照ください|
